# ميليجي - Melegy AI

نسخة عربية مجانية من ChatGPT مع مميزات متقدمة للذكاء الاصطناعي! 🚀

## المميزات الرئيسية

### 1. **محادثة ذكية** 💬
- استخدام Groq API المجاني للحصول على ردود سريعة وذكية
- دعم كامل للغة العربية والإنجليزية
- نموذج Mixtral-8x7b المتقدم
- محفوظات محادثات آلية

### 2. **توليد الصور** 🖼️
- إنشاء صور احترافية من الكلمات
- دعم APIs متعددة:
  - **Pollinations.ai** - توليد سريع بجودة عالية
  - **HuggingFace** - نماذج متقدمة
  - **Prodia** - توليد متكامل
- تحسين الـ prompts تلقائياً

### 3. **تحريك الصور** 🎬
- تحويل الصور الساكنة إلى فيديوهات متحركة
- الحفاظ على هوية الأشخاص بنسبة 100%
- تحريك سلس واحترافي
- دعم APIs:
  - Replicate
  - D-ID
  - Loom

### 4. **تعديل الصور** ✏️
- تحسين وتطوير الصور الموجودة
- استخدام Clipdrop API
- معالجة ذكية للتعديلات

### 5. **دمج عناصر الصور في الفيديو** 🎥
- دمج أشخاص من صور في فيديوهات
- معالجة متقدمة باستخدام Python
- نتائج احترافية

### 6. **تحريك الصور (Loop)** 🔄
- إنشاء رسوم متحركة سلسة
- حركات سلسة وطبيعية
- دعم أنواع حركات مختلفة

## البدء السريع

### المتطلبات
```bash
Node.js 18+ و npm
```

### التثبيت

1. **استنساخ المشروع**
```bash
git clone <repository>
cd v0-melegy-app
```

2. **تثبيت الحزم**
```bash
npm install
```

3. **إضافة متغيرات البيئة**
```bash
# .env.local
GROQ_API_KEY=your_groq_key
REPLICATE_API_KEY=your_replicate_key # اختياري
DID_API_KEY=your_did_key # اختياري
LOOM_API_KEY=your_loom_key # اختياري
```

4. **الحصول على المفاتيح**

#### Groq API (مجاني - ضروري)
- اذهب إلى https://console.groq.com
- أنشئ حساباً مجانياً
- انسخ API Key

#### Replicate (اختياري - لتحريك الصور)
- اذهب إلى https://replicate.com
- أنشئ حساباً (مع credits مجاني)
- انسخ API Token

#### D-ID (اختياري)
- اذهب إلى https://www.d-id.com
- أنشئ حساباً
- احصل على API Key

5. **تشغيل التطبيق**
```bash
npm run dev
```

اذهب إلى http://localhost:3000

## كيفية الاستخدام

### المحادثة الأساسية
```
المستخدم: السلام عليكم، كيفك؟
ميليجي: وعليكم السلام ورحمة الله، أنا بخير! كيف أساعدك اليوم؟
```

### توليد صورة
```
المستخدم: اعملي صورة لقط أسود جميل في الشمس
ميليجي: [سيولد صورة احترافية]
```

### تحريك صورة
1. اضغط على أيقونة "تحريك صورة"
2. اختر صورة
3. اكتب وصفاً للحركة (مثل: حركة طفيفة بلطف)
4. سيتم إنشاء فيديو متحرك

## الخيارات المتقدمة

### تخصيص النموذج
يمكنك تغيير نموذج Groq في `lib/groqService.ts`:

```typescript
// النماذج المتاحة:
// - mixtral-8x7b-32768 (سريع وقوي)
// - llama-3.1-70b-versatile (أقوى)
// - llama-3.3-70b-versatile (الأحدث)
```

### إضافة APIs جديدة
1. أنشئ ملف service جديد في `lib/`
2. أضف دالة في `app/api/`
3. استخدمه في chat page

## استكشاف الأخطاء

### خطأ: GROQ_API_KEY غير موجود
- تأكد من إضافة `GROQ_API_KEY` في `.env.local`
- أعد تشغيل السيرفر

### الصور لا تتولد
- تحقق من اتصال الإنترنت
- جرب بـ prompt أبسط
- تأكد من الـ API alternatives متاحة

### الفيديو بطيء
- استخدم Replicate API للسرعة
- قلل مدة الفيديو المطلوبة
