================================================================================
🚀 طريقة الاستخدام
================================================================================

الخطوة 1: احصل على Groq API Key (ضروري)
  ➤ اذهب إلى: https://console.groq.com
  ➤ انسخ API Key
  ➤ ضعه في: .env.local (GROQ_API_KEY=...)
  ➤ الوقت: 5 دقائق فقط!

الخطوة 2: شغل التطبيق
  ➤ npm install
  ➤ npm run dev
  ➤ اذهب إلى: http://localhost:3000

الخطوة 3: ابدأ الاستخدام
  ➤ اضغط "ابدأ الآن"
  ➤ ابدأ المحادثة
  ➤ استمتع بالمميزات!
