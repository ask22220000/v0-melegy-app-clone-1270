🚀 طريقة الاستخدام
═══════════════════════════════════════════════════════════════════════════

الخطوة 1: احصل على Groq API Key
   • زر https://console.groq.com
   • سجل حسابك (مجاني)
   • انسخ API Key

الخطوة 2: أضف المفتاح
   • أنشئ ملف .env.local
   • أضف: GROQ_API_KEY=gsk_your_key_here

الخطوة 3: شغل التطبيق
   $ npm install        # مرة واحدة
   $ npm run dev        # ابدأ الآن

الخطوة 4: افتح المتصفح
   • http://localhost:3000
